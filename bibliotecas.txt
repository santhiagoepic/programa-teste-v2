Esse código é um programa em Python que cria uma interface gráfica para buscar uma palavra-chave em arquivos PDF, Word, Excel e PowerPoint dentro de um diretório. Ele usa diversas bibliotecas para leitura de arquivos, interface gráfica e processamento assíncrono. Vou explicar cada parte detalhadamente.

files = []
for root, _, filenames in os.walk(directory):

if file_path.endswith(".pdf") and search_pdf:
    with fitz.open(file_path) as pdf_doc:
        for page_num in range(len(pdf_doc)):
            text = pdf_doc[page_num].get_text()
            if keyword.lower() in text.lower():

                found = True
                break
Abre cada página do PDF e verifica se a palavra aparece no texto.

Editar
elif file_path.endswith(".docx") and search_docx:
    doc = docx.Document(file_path)
    for para in doc.paragraphs:
        if keyword.lower() in para.text.lower():
            results.append(f"{file_name} (Word){file_info}")
            found = True
            break
Percorre os parágrafos dos arquivos Word (.docx) e procura a palavra.

python

Editar
elif file_path.endswith(".xlsx") and search_xlsx:
    df = pd.read_excel(file_path, engine='openpyxl')
    if df.astype(str).apply(lambda x: x.str.contains(keyword, case=False, na=False)).any().any():
        results.append(f"{file_name} (Excel){file_info}")
        found = True
Converte os dados do Excel em texto e verifica se a palavra-chave está presente.

python
Copiar
Editar
elif file_path.endswith(".pptx") and search_pptx:
    presentation = pptx.Presentation(file_path)
    for slide_num, slide in enumerate(presentation.slides, start=1):
        for shape in slide.shapes:
            if hasattr(shape, "text") and keyword.lower() in shape.text.lower():
                results.append(f"{file_name} - Slide {slide_num}{file_info}")
                found = True
                break
Percorre os slides do PowerPoint e verifica se a palavra está no texto.
